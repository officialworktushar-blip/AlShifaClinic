# Project rules

- Stack: React (Vite), Tailwind CSS v4 (no tailwind.config.js — theme defined via @theme in src/index.css), Framer Motion, react-router-dom. Already installed — do NOT run npm install or scaffolding commands.
- Environment: Windows, PowerShell (Git Bash also used sometimes).
- Do NOT run npm run dev or npm run build to "verify" your work unless explicitly asked. Just write/edit files and stop.
- Work on ONE component or page at a time. Finish it, then stop and report.
- Do NOT write test/verification/link-checker scripts unless explicitly asked.
- If a command fails once, stop and report the exact error — do not retry variations or guess.
- Never fabricate error messages, file contents, or panel output you cannot actually see.
- Keep todo lists to 5 items max per request.
- Assets are in project/public/assets (logo.png, man.jpeg, woman.jpeg, reviews/, services/, treatments/) — use real filenames found there, do not invent paths.
